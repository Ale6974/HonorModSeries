# Honor Mod Series — RimWorld 1.7

실제 설치된 **RimWorld 1.7.4985 rev1269 / unstable**을 기준으로 만드는 개발용 MVP입니다. 전체 명세의 완성판이 아닙니다. 현재 배포 대상은 Honor.Core 하나입니다.

## 현재 구현

- `Need_Honor`: 0~1 명예, 5단계(0 / .2 / .4 / .6 / .8). 자연 감소는 하루 기본 .001이며 현재 단계 하한에서 멈춥니다. 사건은 단계를 낮출 수 있습니다.
- 실제 성공한 `Insult` 감지 → 피해자가 신청자, 모욕자가 피신청자가 되는 강제 결투 대기열. 같은 모욕으로 바닐라 소셜 싸움이 겹쳐 시작되지 않습니다.
- 기본 참가자: 같은 플레이어 정착지의 비적대 인간형, 생물학적 18세 이상. 노예·포로·미성년자는 기본 제외하고 설정으로 허용합니다. 수면·의식불명·치료 필요·징집 중에는 준비를 미룹니다.
- 신청자 이념의 명예 결투 교리가 우선합니다. Ideology가 없거나 해당 교리가 없으면 산업 이상은 선혈전, 그 이전 기술은 항복전입니다. 이 기술별 대응은 게임 API의 사실이 아니라 **이 프로젝트의 조정 가능한 설계 결정**입니다.
- 선혈전 / 항복전(통증·다운) / 사망전 상태 관리. 검·단검·리볼버 기본 허용. 무기 Def·재료·품질이 같고 내구도 차이가 10% 이하여야 합니다. 추가 사격무기는 설정으로 허용하되 비폭발 탄환형만 받습니다.
- 결투장 지정, 집결, 방어구 탈의와 일반 의복 유지, 종료 후 근처 방어구 재착용. 실제 바닐라 근접 공격·사격을 사용합니다.
- 제삼자·화재·적·막힌 경기장·장비 교체·중단·외부 피해에 대한 안전 중단. 결투 참가자의 오사 피해를 막고, 종료 직후 600틱 동안 추가 피해를 억제합니다.
- 종료 시 즉시 무약물 현장 처치. 근처 접근 가능한 의사가 있으면 그 능력을 사용하고, 없으면 게임의 무의사 처치 계산을 사용합니다. 상처가 즉시 낫는 기능은 아닙니다.
- 승패 명예 변화, 바닐라 소셜 기억, 명예 집착·명예로움·비열함 특성, 설정 화면, 한국어/영어 UI, Scribe 저장, 구조화 로그, 확장 API.

## 설치와 첫 플레이

1. 게임 버전과 Harmony를 위 검증 버전에 맞춥니다. 1.6용 DLL로 대체하지 마세요.
2. 제공된 `Honor.Core-MVP.zip`을 풀어 `RimWorld/mods/Honor.Core/About/About.xml`이 되도록 복사합니다. 소스에서 설치한다면 먼저 아래 빌드를 실행한 뒤 `Mods/Honor.Core` 폴더만 복사합니다.
3. 모드 목록에서 Harmony와 Honor.Core를 활성화합니다. `TestMods`는 일반 플레이에 설치하지 않습니다.
4. 테스트 정착지에서 주민을 선택하고 **결투장 지정**으로 빈 평지 중심을 선택합니다. 근접전 반경 4, 사격전 반경 7칸을 비워 두세요.
5. 참가자 두 명에게 같은 재료·품질의 단검이나 검, 또는 같은 품질의 리볼버를 장비합니다. 치료를 마치고 징집을 해제합니다.
6. 실제 모욕이 발생하면 자동으로 의무가 기록되고 준비가 끝난 뒤 결투가 시작됩니다. 개발자 모드의 `DEV: Honor insult`로도 재현할 수 있습니다. 자동 준비를 끈 경우 **대기 결투 진행**을 사용합니다.
7. 위험하면 **결투 안전 중단**을 사용합니다. 승리자는 나오지 않습니다.

## 빌드

.NET **10 SDK**가 필요합니다. 게임에 동봉된 런타임만으로는 빌드할 수 없습니다. 게임·Harmony DLL은 저장소나 배포 ZIP에 포함하지 않습니다.

```powershell
Copy-Item GamePaths.props.example GamePaths.props
# GamePaths.props의 RimWorldDir / HarmonyDll을 실제 설치 경로로 수정
./tools/Build.ps1 -DotnetPath 'C:/path/to/dotnet.exe'
```

검증 당시 이 작업 환경에는 SDK가 없어 작업용 `work/tooling/dotnet`에 SDK 10.0.402를 설치했습니다. 시스템 dotnet 설정은 바꾸지 않았습니다.

## 중요한 현재 제한

승리자의 은·물품·우호도·합류 요구는 아직 구현하지 않았습니다. 정착지 방문객·다른 세력·월드맵 결투, 대리 결투, 귀족 작위, 가족·소문·숙적, 맹세·의식도 후속 모듈입니다. 별도 평판 화폐는 만들지 않습니다.

자동화 검사는 실제 1.7 엔진에서 수행하지만 화면 조작·장기 정착지 플레이와 대규모 모드 조합 검증은 별개입니다. 비폭발 기본 무기부터 사용하세요. CE·특수 피해·신체 무기·마법 공격의 호환성은 검증하지 않았습니다. 단발 공격 자체로 치명상이 생길 수 있어 선혈전·항복전도 생존을 보장하지 않습니다.

이 저장소는 로컬 Git 저장소입니다. GitHub 원격 저장소 생성·업로드는 수행하지 않았습니다.
