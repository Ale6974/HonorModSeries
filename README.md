## 모듈과 사용법

| 모듈 | 구현한 기능 | 시작 방법 |
|---|---|---|
| Core | Need 명예 5단계, 모욕→강제 결투→종료→처치→명예·소셜 기억, 이념 규칙, 장비 조건, 결투장, 세 특성, 설정·저장·API | 빈 평지에 결투장을 지정하고 양쪽에 같은 허용 무기를 장비 |
| Society | 모욕자의 사과 제안과 피해자의 수락, 목격 기억, 하루 후 정착지 소문, 혈연 명예, 반복 모욕 숙적 | 결투 준비 전 당사자 버튼으로 사과 제안/수락 |
| Nobility | Royalty 작위별 명예 민감도, 귀족의 대리 결투와 본인에게 돌아오는 결과 | 작위 보유자를 선택해 대기 결투의 대리인 지정 |
| Diplomacy | 비적대 정착지 모욕에 대응하는 월드 퀘스트, 대표 생성·동일 무기·결투, 은과 우호도 결과 | 월드맵 비적대 정착지의 ‘정착지 모욕에 대응’ → 상단 이동 → 도착한 대표 선택 |
| Oaths | 목격자 2명과 600틱 의식, 5일 승리/평화 맹세, 성공·위반 명예와 기분 기억, 의례적 칭호 | 주민의 ‘맹세하기’ 선택, 10칸 이내 깨어 있는 목격자 2명 확보 |

Core는 Harmony 3만 필요합니다. 각 부속 모드는 Core 0.2.1 이상과 Harmony가 필요하며 서로는 필요하지 않습니다. **Nobility만 Royalty DLC가 필수**입니다. DLC가 없다면 Nobility를 제외한 구성을 사용하세요. [정확한 의존성 표](docs/DEPENDENCIES.md).

모든 플레이어 문구는 게임의 영어/한국어 언어 설정을 따릅니다. 다른 언어에서는 기본 영어를 사용합니다. 사용자 언어 설정을 바꾸지 않습니다.

## 로컬 설치와 첫 결투

1. 배포 ZIP의 `Honor.*` 폴더를 `RimWorld/mods`에 복사합니다. `TestMods`는 일반 플레이에 설치하지 않습니다.
2. Harmony → 게임/DLC → Core → 선택 부속 모드 순으로 활성화합니다. 로컬본과 Workshop본을 중복 활성화하지 마세요.
3. 주민을 선택해 결투장을 지정합니다. 근접 반경 4칸, 사격 반경 7칸은 비워 두세요. 양쪽에 같은 재료·품질의 검/단검 또는 같은 품질 리볼버를 장비합니다. 내구도 차이는 10% 이하여야 합니다.
4. 실제 모욕 또는 개발자용 모욕 버튼으로 의무가 생성됩니다. 치료 필요·수면·의식불명·징집 중에는 준비를 연기합니다. 미성년자·노예·구금은 기본 제외하며 Core 설정으로 허용합니다.
5. Society 또는 Nobility가 있으면 자동 준비까지 최소 600틱의 여유가 있습니다. 자동 준비를 끄면 수동 진행할 수 있습니다. 사과는 피해자가 수락해야 결투가 취소됩니다.
6. 신청자 이념 규칙이 우선합니다. 교리가 없으면 산업 이상 선혈전, 그 이전 항복전입니다. 종료 시 즉시 무약물 처치로 출혈을 안정화하고 근처 방어구를 돌려 입습니다.

개발용 로컬 설치: `./tools/Install-Local.ps1 -RimWorldDir '게임 경로' -Activate`. 기본값은 다섯 모드 설치이며 Royalty가 활성화되지 않았으면 Nobility는 활성화하지 않습니다. 기존 모드·설정을 `.local`에 백업하고 다른 모드 순서와 언어를 유지합니다. `-Modules Core,Society`로 선택 설치할 수도 있습니다.

## 세부 규칙과 제한

명예는 0~1 Need이며 0/.2/.4/.6/.8의 5단계입니다. 하루 기본 .001 자연 감소는 현재 단계 하한에서 멈춥니다. 사건은 단계를 낮출 수 있습니다. 별도 평판 화폐는 없고 바닐라 소셜 기억·혈연·세력 우호도를 사용합니다.

Society: 15일 이내 같은 방향 모욕이 3회면 양쪽 숙적 기억(-20 의견, 30일)을 얻습니다. 수락한 사과는 모욕 명예 손실을 돌려주고 모욕자에게 -.01, 피해자에게 +6 의견 기억을 줍니다. 정당한 승리자의 살아 있는 혈연은 +.015 명예, 현장 목격자는 +4 의견, 하루 뒤 다른 정착민은 +2 의견 기억을 얻습니다. 불명예 당사자 혈연은 -.02 명예입니다.

Nobility: 가장 높은 작위의 seniority를 사용해 1.1 + min(rank,10) × .05 배율을 적용합니다. 대리인이 싸워도 최초 신청자의 규칙을 유지하고 결과 명예는 본인에게 적용합니다. 승리 대리인에게는 추가 +.02 명예입니다.

Diplomacy: 무작위 사건 대신 **플레이어가 비적대 정착지에서 시작**합니다. 2~8타일 근처 장소·10일 기한·세력별 10일 대기 기간을 사용합니다. 현장 상대는 허용 무기를 맞추며, 생성된 상대 대여 무기는 종료 시 회수됩니다. 승리하면 현장 은 100·우호도 +10, 패배·중단·만료는 우호도 -5입니다. 일반 주민 결투의 자유로운 보상 협상은 구현하지 않았습니다. 상단의 다른 인원은 결투장 밖에 두세요.

Oaths: 정당한 결투 승리 또는 모욕·불명예 없이 5일 버티기입니다. 성공 +.06 명예·기분 +5, 실패 -.1·기분 -8입니다. 칭호는 능력치나 Royalty 작위를 주지 않는 모드 의례 호칭이며 최근 위반 시 표시를 억제합니다.

선혈전·항복전도 단발 치명상 생존을 보장하지 않습니다. 항복은 통증/다운으로 판정합니다. 고의/사고 살해 구별과 종료 후 보복 판별, 물품·합류 요구 협상, 대규모 모드·CE 호환성, 장기 플레이는 미완료입니다. 자세한 범위는 [STATUS](docs/STATUS.md), 실제 검사 기록은 [TESTING](docs/TESTING.md)를 확인하세요.

출시 전 검토와 수정 내용은 [RELEASE-REVIEW](docs/RELEASE-REVIEW.md)를 확인하세요.

## 빌드와 개발

다음 기능은 [봉신·식민지 계약 설계](docs/CONTRACTS-DESIGN.md)에 정리했습니다. 세력 간 봉신, 개인 봉신, 외국 정착지별 자치·공납·보호 계약을 대상으로 하며 `Honor.Contracts.Rules`와 별도 규칙 검사를 추가했습니다. **아직 게임 내 사용 가능한 Contracts 모드는 아닙니다.** 공개 0.2.1의 다섯 모드에는 포함하지 않습니다.

추가된 군사 경로는 정착지 공격·포위 후 항복/점령 계약, 봉신 피습·포위에 따른 보호 요청입니다. 체결 경위와 요청 연결 규칙은 구현했으며, 실제 정착지 보존·포위 진행·이벤트 생성·방어 퀘스트는 아직 게임에 연결하지 않았습니다.

자유도시는 유효한 봉건계약이 없는 정치적 지위로 설계했습니다. 플레이어 정착지는 기지 가치가 기준(제안 100,000)에 도달하면 종주와 협상하거나 자유도시로 남도록 선택합니다. 지위 판정·반복 선택 방지·협상 전환 규칙은 구현했으며, 실제 선택 편지·가치 관측·설정 UI·저장은 아직 게임에 연결하지 않았습니다.

세력 명예의 공적 사건 장부, 계약별 양방향 신뢰, 낮은 종주 명예·불신에 따른 영지 이탈 압박도 규칙 계층에 구현했습니다. 경고와 대응 기간을 거쳐 이탈 판단 가능 상태를 계산하며, 이 값만으로 계약을 파기하지 않습니다. 실제 게임 사건 평가·화면·저장·독립/반란 AI는 아직 없습니다. 개인 명예 Need와 기존 소셜 기억·우호도 체계는 유지합니다.

“구원하러 오면 봉신이 되겠다”는 자유도시/저명예 세력 영지의 조건부 제안도 규칙 계층에 추가했습니다. 수락·실제 구원·기존 계약 정리 뒤 약속한 문안으로 정착지 계약을 체결하며 기한과 증거/사건 중복을 검사합니다. 실제 미션 생성·전투·외교 결과·저장과 영한 UI는 아직 연결하지 않았습니다.

.NET 10 SDK와 사용자 소유의 게임·Harmony DLL이 필요합니다. 개발 스크립트는 PowerShell 7에서 검증했습니다. `GamePaths.props.example`을 `GamePaths.props`로 복사해 경로를 설정한 뒤 `./tools/Build.ps1 -DotnetPath 'dotnet.exe 경로'`를 실행합니다. 게임·Harmony·Steamworks DLL과 세이브·개인 설정은 배포하지 않습니다.
