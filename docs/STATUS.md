# 요구사항 상태

## MVP에 들어간 기능

Need 기반 명예·5단계 하한·매우 느린 단계 내 감소·사건에 의한 하락, 성공한 모욕 감지, 거절 버튼 없는 결투 의무, 제외 대상 설정, 의식불명 연기, 신청자 이념 우선, 세 가지 종료 규칙, 기본 무기 허용·동일 장비 조건, 일반 의복 유지·방어구 탈의, 지정 결투장과 피해 차단, 즉시 현장 처치, 승패 명예·관계 기억, 세 특성, 설정·지속성·API·로그를 구현했습니다.

## 부분 구현과 명확한 제한

- 항복은 별도 대화 선택이 아니라 통증 또는 다운 상태로 판정합니다.
- 동일 장비는 Def·재료·품질과 내구도 근사 비교입니다. 유전자·임플란트·스킬·모드 인챈트까지 같게 만드는 규칙은 없습니다.
- 방어구는 바닐라 Armor 태그·방어구 카테고리로 판별합니다. 임의 모드의 잘못된 태그까지 추정하지 않습니다.
- 응급치료는 `TendUtility.DoTend`를 바로 호출하는 현장 안정화입니다. 의사 이동·약품 예약·구조 작업은 후속입니다.
- 비사망전에서 실제 사망을 만든 경우 명예 손실·근처 목격자의 부정적 소셜 기억을 적용하는 훅이 있습니다. 고의·사고·치료 방치의 구별과 종료 후 보복 살해 판별은 아직 완성하지 않았습니다.
- 오사 방지는 참가자에게서 Pawn으로 가는 피해를 차단합니다. 종료 후 600틱은 해당 참가자의 다른 Pawn 공격도 억제하는 보수적인 보호 구간입니다. 구조물·동물 이외 Thing 피해 경로와 임의 특수 Verb 전체를 격리하는 전투 샌드박스는 아닙니다. 폭발·비탄환 사격을 허용하지 않습니다.
- 현재는 같은 플레이어 정착지 내 비적대 인간형 대상입니다. 방문객이나 적대 세력에 강제 결투를 적용하지 않습니다.
- 안전 중단 시 의무는 취소됩니다. 중단 원인별 재신청·기권·불명예 정책은 후속입니다.

## 아직 구현하지 않은 기능

승리자의 적정 은·물품·우호도·합류 요구와 상한/권한 검증, 명예가 낮을 때의 추가 행동·무드 효과, 귀족 민감도·대리 결투, 사과·소문·가족 명예·숙적, 월드맵 대표 퀘스트, 맹세·의식·칭호. 이 항목들은 전체 개발 명세에서 빠진 것이 아니라 후속 단계입니다.

## 출시 범위

개발용 MVP. 실제 설치 DLL로 컴파일하고 엔진 통합 검사를 실행합니다. 안정판 1.7 또는 이후 패치 호환성을 자동으로 주장하지 않습니다. 화면·장기 플레이·다양한 DLC 조합·CE 호환성 검증 전 정식 완성판으로 표기하지 않습니다.
