# 공개 전 검토 — 0.2.1

검토 대상: 0.2.0 공개 코드 `c8329dc`, 설치된 RimWorld 1.7.4985 rev1269 / Waylith / Harmony 3, 다섯 모드의 소스·저장 데이터·배포 경계·의존성·언어와 게시 설명.

## 판정

0.2.0에서는 아래 8개 문제가 있어 모음집 공개 전에 수정을 권했습니다. 수정본은 0.2.1입니다. 여전히 **실험판**이며 자유 보상 협상·고의 살해 완전 구분·장기 플레이·대형 모드 호환성을 완료한 정식판이라고 안내하면 안 됩니다. 모음집은 구성과 API Public 설정만 완료됐고, 사용자 요청에 따라 마지막 Steam 웹 공개 버튼은 대기 상태입니다.

## 발견 및 수정

| 중요도 | 재현 조건과 영향 | 수정 |
|---|---|---|
| P1 | 외교 대표의 생성 무기를 줍거나 가져가면 비용 없이 같은 무기를 얻을 수 있음 | 생성 무기를 대여물로 참조 저장하고 승리·실패·중단에 회수. 다른 소유자의 인벤토리로 옮겨도 회수하며 플레이어 원래 무기는 보존. 제거한 무기의 결투 참조도 정리 |
| P1 | 대기 결투 당사자가 맵을 떠나면 pending 의무가 계속 남음 | 사망·비소환·다른 맵·귀족 본인의 이탈을 점검해 취소. 자동 준비가 꺼져 있거나 앞에 다른 대기가 있어도 전체 대기열 정리 |
| P1 | 외교 결투 신청자가 이미 맵을 떠난 뒤 종료 이벤트가 오면 신청자의 Map이 없어 퀘스트 미종료 | 신청자 현재 맵 대신 결투 대표의 신원으로 해당 월드 장소를 찾아 실패 처리 |
| P2 | 사과 제안 후 상대가 멀어지거나 의식/맵 상태가 바뀌어도 수락 가능 | 제안과 수락 양쪽에서 살아 있는 상태·같은 맵·의식·12칸 거리를 재검증 |
| P2 | 승리 맹세 기한 이후, 주기 검사 전 승리하면 늦은 성공을 허용 | 승리 등 사건 처리 전에 기한을 즉시 확정 |
| P2 | 평화 맹세 기한을 이미 채웠어도 주기 검사 전 모욕으로 실패 처리 | 마감 성공을 먼저 확정해 기한 뒤 사건을 분리 |
| P2 | 비사망전의 불명예 승리자에게 벌점과 별개로 일반 승리 명예·존중 기억도 부여 | 불명예가 기록된 결투에는 일반 승리 보상을 부여하지 않음 |
| P2 | 새 외교 결투장의 돌덩이 등 비건물 장애물이 Standable 검사를 막아 결투가 시작되지 않을 수 있음 | 준비 단계에서 Pawn을 보존하면서 비기립 장애물·화재도 정리. 실제 돌덩이를 배치해 막힘을 재현한 뒤 준비 함수로 해소 확인 |

관련 보강: 맹세 위반 시각을 별도로 저장해 칭호 제한을 실제 위반 시점부터 계산합니다. 0.2.0 기록의 새 필드는 게임 로드가 끝난 뒤 이전하며, 옛 기록에서 알 수 없는 정확한 위반 시각은 기한과 로드 시각 범위로 보수적으로 추정합니다. 신규 기록은 정확한 시각을 저장합니다.

재모욕이 대기/진행 결투와 바닐라 소셜 싸움을 겹치게 하지 않도록 가드를 확장했습니다. 결투 시작에는 같은 맵·비적대 조건을 다시 확인합니다. 로컬 설치기는 선택 부속 모드에 Core를 자동 포함하고, 전체 빌드/대상 검사를 마친 뒤 파일 교체를 시작하며 백업 이름 충돌을 피합니다.

## 검사 증거

수정 전 실제 엔진 Review 검사에서 첫 7개가 함께 실패한 것을 확인했습니다. 이후 실제 경기장 검사에서 돌덩이의 기립 방해도 확인해 8번째 항목을 추가했습니다. 수정 후 Review·기존 세이브 재개 결과와 배포 확인은 [검사 기록](TESTING.md), [선별 메시지](evidence/release-review-0.2.1.txt)에 기록합니다.

검사는 실제 게임 엔진과 격리된 저장 폴더를 사용합니다. GUI 클릭·장기 플레이를 통과한 것으로 확대하지 않습니다. 특히 상단의 실제 왕복 이동, 결투장 선택 화면, 장기 정착지·대형 전투 모드 조합은 별도 수동 검증 대상입니다.

## 의존성과 배포 검토

- Core에는 Core/Rules DLL만, 부속 모드에는 자신의 DLL만 배포합니다. 게임/Harmony/Steamworks DLL·PDB·테스트 모드·개인 설정은 제외합니다.
- 모든 모드는 Harmony 3 for 1.7이 필요하고 부속 모드는 Core 0.2.1 이상이 필요합니다. Nobility만 Royalty DLC가 필수입니다. 부속 모드끼리는 필요하지 않습니다.
- 게임의 ModDependency는 패키지 유무를 검사하며 최소 버전 숫자까지 강제하지 않습니다. 따라서 Core와 부속 모드를 함께 업데이트해야 합니다. 최소 버전은 About 표시와 문서/Workshop 설명에 명시합니다.
- 영어·한국어 키/자리표시자와 실제 번역 적용을 검사합니다. 사용자 언어/기존 다른 모드 순서는 보존합니다.
- 모드별 Workshop Required Items와 Nobility의 Royalty App Dependency는 게시 후 manifest와 다시 비교합니다. 모음집 API Public 값은 웹 공개 완료의 증거가 아닙니다.
