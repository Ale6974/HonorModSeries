# Honor.Contracts 연결 흐름 개발 미리보기

## 용도와 상태

사용자가 선택한 전체 흐름 우선 개발의 첫 연결 버전이다. `PoliticalWorld`는 실제 Faction과 별개의 정치 주체 ID를 사용한다. `Honor.Contracts.Preview`는 **별도 선택형 개발 모드**이며 공개 Core/Society/Nobility/Diplomacy/Oaths에 자동으로 포함되지 않는다. 실제 플레이 증명 없이 완성 모드로 Workshop에 게시하지 않는다.

설치 게임 1.7.4985 rev1269의 Assembly-CSharp/UnityStubs/Waylith와 Harmony 3 RC DLL로 컴파일했다. 새 게임 실행·UI 조작·Scribe 게임 저장 재로딩은 수행하지 않았다. 빌드는 API 참조 검사이지 엔진 동작 증거가 아니다.

## 이번에 연결한 범위

### 1단계: 방문 도시의 일반 거래 물품 보존 (0.3.7)

기존 계약의 개별 소속 집행과 통합 봉신 이전에서 **이미 거래한 NPC 도시도 맵이 미로딩이고 저장된 주민이 없으면** 일반 물품을 보존한 채 이전하도록 작성했다. 초기 세계 재편/연합 배치는 계속 미방문 도시만 사용한다. 사람·동물·시체·축소 건물·직접/컴포넌트 보관함 재고, 알 수 없는 정착지/상단 하위 클래스는 제외한다. 플레이어 기지와 Pawn 소속은 바꾸지 않는다.

검토 시 `GetDirectlyHeldThings()`로 현재 재고만 읽으며 `Goods`/`StockListForReading`으로 재생성하지 않는다. 물품 ID·Def·재료·수량·내구도·품질, 방문 여부·보관자 존재·재입고 시각을 SHA256으로 요약한다. 검토 후 재고가 바뀌면 다시 검토해야 한다. 준비 장부에 같은 근거를 저장하고 실제 목적 소속과 동일 재고를 확인해야 완료한다. 중단 복구 때 출발 소속 그대로여도 재고가 다르면 취소하지 않고 보류한다. 이 요약은 열거한 상태의 변경 감지이며 모든 물품 컴포넌트 상태/모드 호환성이나 저장 파일 보안 인증을 보장하지 않는다.

기존 재고를 버리거나 복제하지 않으며 이미 만료된 재고가 없는 도시도 새 물품 없이 검사한다. 목적 세력의 거래 종류는 native getter를 따르고 향후 재입고·주민 생성은 목적 세력 기준이다. 도시 표시 material 캐시만 비우며 풀의 material을 파괴하지 않는다. 옛 v1 실행 기록의 새 필드는 null이면 쓰지 않아 미변경 장부 JSON과 진행 중 정치 전환의 취소 해시를 유지한다. 이전 개발판의 미방문 전용 준비 건을 새 방문 증거로 승격하지 않는다.

실제 맵/주민·특수 재고 이관, 문화 보존, 전시 점령·NPC 다단계 계층은 남아 있다. 새 코드와 규칙 검사·설치 DLL 빌드만 검증하며 실제 자원 보존·캐시 갱신·엔진 저장/복구·다른 모드 패치는 게임 실행으로 검증하지 않았다. 1단계 완료나 Workshop 공개판을 뜻하지 않는다.

### 1단계: 소속·봉신 이동 통합 전환 (0.3.6)

**플레이어 정치 소속**에서 연합 가입, 합의 해약 후 연합 복귀, 서명된 새 종주 계약을 검토할 때 대외 관계와 모든 활성 직속 NPC 봉신 도시 목록을 함께 표시한다. 기존처럼 플레이어 이적 후 별도 일괄 버튼을 반드시 눌러야 하는 흐름을 바꿨다. 한 번 확정하면 플레이어 소속 명령→공유 외교→도시별 실제 이전→전체 목적지 확인을 이어서 수행한다. 기존 저장의 수동 정렬 화면도 유지한다. NPC끼리의 다단계 생성/후손 전체 집행을 구현한 것은 아니다.

이전 봉신 계약의 실제 양측 해약·기록된 종주 일치, 새 계약의 활성 상태/실제 권위자, 연합 통보기간과 미완료 물품 이전, 살아 있는 목적 세력 대표·퀘스트/우호도 상한, 봉신 전체의 누적 이전 가능성을 먼저 검사한다. 연합 복귀에는 이미 존재하는 유효한 연합이 필요하다. 새 외교에서 봉신 원 세력과 적대하게 되면 이 평화 이전 어댑터로 이동하지 않고 시작 전에 보류한다. 당시에는 방문/로딩된 도시의 새 소속 이전을 보류했으며, 0.3.7에서 아래 제한에 따라 일반 물품 방문 도시에 한해 확장했다. 이미 목적 세력에 도착한 방문 도시는 다시 옮기지 않는다.

`AllegianceTransitionLedger`/`PoliticalTransitionLedger`는 하나의 준비/소속 적용/완료/취소 의도를 버전 1 JSON으로 저장한다. 이전·예상 소속 명령 이력과 대상 계약 집합, 이전 영지 장부의 SHA256 및 확인 시각을 보관한다. 해시는 취소 시 장부 일치 확인용이며 저장 파일의 보안 인증이 아니다. 소속 기록만으로 도시 이전 완료를 주장하지 않는다. 과거 전환 이력은 PlayerAllegiance 명령과 도시별 장부에 남고 조정 장부에는 현재 또는 마지막 의도만 둔다.

중단된 경우 이 창에서 미확정 도시를 확인하고 **현재 목적지와 남은 도시 재검토** 후 재개한다. 원래 명령 이력의 동일한 앞부분과 현재 소속·계약, 실제 해약/활성 계약 및 정확한 봉신 집합을 다시 확인한다. 같은 권위자의 중단/재확인 명령은 허용하지만 다른 정치 소속으로 바뀐 이력으로 완료 처리하지 않는다. 소속 적용 전이고 플레이어 명령 이력과 영지 장부가 그대로인 준비 건만 취소할 수 있다. 부분 적용된 소속·도시는 자동 롤백하지 않는다. 로드 후 자동 재실행도 하지 않는다.

진행 중에는 다른 계약/소속 변경·초기 세계 재편·관리청 설립/재개·새 실물 납부를 보류한다. 실제 소유권 확인/미이동 취소는 허용한다. 기존 미납·영수증·해약 기록은 보존하며 복귀나 이적이 채무를 면제하지 않는다. 연합 회비·정당한 일방 독립·사라진 권위자에 대한 비상 전환은 미구현이다. 외부 모드가 대상 계약/세력을 변경해 검증할 수 없으면 보류 상태를 유지한다.

추가 54개 순수 검사, 설치 DLL 빌드와 영한 키를 검증했다. 실제 전환 창·외교 알림/재진입·세력/도시 변경·엔진 Scribe 왕복·중단 복구는 실행하지 않았다. 코드 단계 구현을 실제 플레이 성공으로 취급하지 않으며 1단계 완료/Contracts Workshop 게시도 보류한다.

### 1단계: 영지 관리청과 봉신 일괄 소속 정렬 (0.3.5)

플레이어 정착지의 **플레이어 정치 소속** 창에서 미소속 상태에 **NPC 영지 관리청 설립**을 선택한다. 실제 비플레이어 세력을 하나 만들고 플레이어와 +100 내부 동맹으로 시작한다. 숨김 생성 override로 무작위 정착지 생성을 억제한 뒤 공개 세력으로 등록한다. 관리청은 플레이어의 종주가 아니며, 독립 플레이어의 봉신 도시를 플레이어 기지로 바꾸지 않고 수용하는 NPC 소속 표현이다. 생성/저장 ID·플레이어 ID를 검증하며 중복/멸망 관리청을 임의로 교체하거나 부활시키지 않는다.

`RealmAdministrationLedger`는 플레이어의 대외 우호도/관계 종류를 관리청에 복사하고 관리 도시의 대외 우호도 사건을 플레이어 쌍으로 전달한다. 외국 종주 외교 공유는 관리청을 별도 대상으로 덮어쓰지 않으며 플레이어와 자기 관리청의 내부 사건도 외국 종주로 우회하지 않는다. 퀘스트/영구 관계 제한·플레이어 상한·소속 중단·내부 적대 충돌 시 관리청 공유를 멈추고 재검사를 요구한다. 무작위 습격·군사 원조·퀘스트 장소 생성은 비활성화했지만 일반 NPC 세력 조회에서 보이므로 모든 퀘스트/모드 호환성을 보장하지 않는다. 바닐라의 내부 우호도 변화도 남아 있다.

관리청의 초기 병종/기술/거래/이념은 OutlanderFactionBase의 산업 외지인 기준이다. 플레이어 기술이나 주민 문화를 복제한 것이 아니다. 현재 언어에 맞는 세력명과 6개 DefInjected 필드를 제공한다. 플레이어 도시·Pawn의 faction은 변경하지 않는다. 관리청 설립 후 실제 계약 장부의 NPC 영지 소속 집행이나 아래 일괄 화면에서 도시 편입을 따로 확정한다.

같은 정치 소속 창의 **현재 정치 소속으로 봉신 도시 정렬**에서 활성 NPC 도시 봉신 전체를 현재 관리청/연합/종주 세력과 대조한다. 누락/중복 대상을 거절하고 각 도시의 실제 소유권·미방문 조건·미완료 이전과 같은 원 세력의 누적 도시 감소를 장부 복사본으로 먼저 검사한다. 실제 원 세력에는 다른 기지를 남긴다. 검증된 플레이어 전용 관리청만 모든 도시가 빠져나가 빈 상태가 될 수 있다. 이미 목적 소속인 도시는 방문/맵이 있어도 이동할 필요가 없지만, 다른 소속의 방문 도시는 여전히 이동을 막는다.

일괄 확정 후에도 실제 이전은 도시별 준비→SetFaction→소유권 확인으로 순차 처리한다. 중단 시 완료 건은 유지하고 미완료 도시를 복구 버튼으로 확인한 뒤 전체를 다시 검토한다. 일부 완료를 전체 성공으로 기록하지 않으며 집행 중 목적지·활성 대상이 달라졌는지도 끝에 검사한다. 저장 후 새로운 세계 상태에서 목록을 다시 만들며 과거 계획을 자동 재실행하지 않는다. 이 0.3.5 독립 정렬 화면에 더해 위 0.3.6에서 소속과 직속 봉신의 통합 확정을 추가했다. 현재 실제 장부가 지원하는 플레이어 직속 NPC 도시만 취급한다. NPC끼리의 다단계 생성은 남아 있다.

추가 37개 순수 검사, 설치 DLL 빌드와 영한 번역을 검증했다. 실제 관리청 생성·외교 재진입·이름 표시·NPC 도시/주민·세력 멸망 판정·퀘스트·Scribe 저장 재로딩은 실행하지 않았다. Contracts Workshop 게시와 1단계 완료 판정은 보류한다.

### 1단계: NPC 영지 소속 집행 (0.3.4)

실제 계약 장부에서 NPC 도시가 봉신인 활성/합의 해약 계약의 **NPC 영지 소속 집행 / NPC territory membership** 창을 연다. 현재 도시·원 세력·목적 세력을 검토한 뒤 별도 확정한다. 활성 계약은 플레이어가 이미 가입해 공유 외교를 적용 중인 비플레이어 연합/종주 세력을 목적지로 삼는다. 합의 해약 계약은 초기 구성 등으로 이미 존재하는 자유도시연합으로 이동한다. 진행 중 제안이 있으면 먼저 해결해야 하며 새 활성 계약이 있으면 옛 해약 기록으로 이를 우회할 수 없다. 이미 목적 세력 소속이라면 추가 이동을 만들지 않는다.

**확정은 실제 NPC 정착지의 Faction을 바꾸며**, 편입 후 대외 외교·향후 주민 생성·거래·기술/이념은 목적 세력 기준이 된다. 기존의 서명 동의 장부는 보존한다. 지금은 로딩된 맵·방문/재고/주민 생성 이력·적대/숨김/임시/멸망/왕실 작위 세력·미완료 실물 이전을 제외하고 원 세력에 다른 기지가 남아야 한다. 대상·목적지 자격과 실제 소유권을 확정 시 다시 검사한다. 플레이어 기지와 Pawn의 소속은 변경하지 않는다.

`TerritoryTransferLedger`는 준비/적용/취소, 원본 정체성·실제 출발/목적 소속·계약·시각을 별도 버전 1 JSON으로 저장한다. 실제 도시/세력 참조는 Scribe로 저장한다. 준비만으로 완료를 주장하지 않으며 실제 목적 소유권·미방문 상태를 확인해야 적용된다. 중단된 건은 실제 목적 소속이면 확인하고, 출발 소속 그대로임을 확인해야 취소한다. 제삼자의 소유권을 강제로 덮어쓰거나 재이동하지 않는다. 해결 전에는 후속 이동과 해당 도시의 계약 동의를 보류한다.

계약의 최초 native owner는 불변의 기준 ID다. 실제 소속이 실행 장부의 마지막 완료 목적지와 일치할 때만 계약 관측에서 최초 정체성에 대응시킨다. 진행 중 이동·현재 외부 점령·소실은 정상 관측으로 변환하지 않는다. 같은 도시와 후속 계약을 다시 맺을 때도 원본 ID를 새 세력 ID로 덮어쓰지 않는다.

독립 플레이어의 봉신 도시를 native `Faction.OfPlayer`로 편입하면 바닐라 플레이어 기지가 되므로 이번에는 이를 거절한다. 영지 관리청과 이적 후 별도 확인형 일괄 정렬은 위 0.3.5 절에서 추가했다. 직속 봉신의 통합 이적과 플레이어의 합의 해약 후 연합 복귀는 위 0.3.6에서 추가했다. 방문한 도시의 맵/주민/재고 보존, NPC끼리의 계층 생성/다단계 후손 집행, 주군 중대 위반에 따른 일방 독립은 남아 있다. **해약 자체가 자동 이동이나 전쟁/보호 임무 완료를 뜻하지 않는다.** 이 제한 중 일반 거래 물품 보존은 0.3.7에서 확장했으며 로딩된 맵·저장된 주민·사람/동물/보관함 재고 이전은 계속 제외한다.

추가 69개 순수 검사와 기존 전체 빌드가 통과했다. 실제 엔진의 소유권 변경·캐시·세력 멸망 판정·생성 주민·거래·저장 복원은 실행하지 않았다. 1단계는 여전히 진행 중이며 Contracts Workshop 배포는 보류한다.

### 1단계: 플레이어 소속과 공유 외교 (0.3.3)

플레이어 정착지의 **플레이어 정치 소속 / Player political allegiance** 명령을 추가했다. 초기 구성에서 만든 연합 가입 또는 실제 장부에 양측이 서명한 플레이어 봉신 계약의 종주를 검토한다. 후보의 공개 대외 관계를 표시하고 별도 확정해야 적용하며, 검토 이후 원본 관계가 바뀌면 재검토를 요구한다. NPC 동의는 연합의 살아 있는 지도자·비적대 상태 또는 기존 양측 서명 계약을 기준으로 하는 임시 정책이다. 초기 기지 가치 성장 알림과 정치 협상 AI는 아직 연결하지 않았다.

확정 시 **모든 플레이어 정착지의 실제 대외 우호도와 적대/중립/동맹 관계가 종주/연합을 따른다.** 종주/연합과의 내부 관계는 +100 동맹으로 시작한다. 세력의 실제 관계 객체를 별도로 유지하면서 값을 복사하고 바닐라 관계 변경 알림을 호출한다. 플레이어가 관련된 우호도 사건은 원래의 변경 허용 조건과 자연 우호도 보정을 확인한 뒤 대표 세력에 전달한다. 이후 외교 변화도 즉시 또는 250틱 주기로 공유하며 관계 종류 변경은 메시지와 일시정지로 알린다. 평의회 표결/전쟁 승인 기능은 아직 없으므로 현재는 플레이어의 외교 사건이 공유 관계에 직접 영향을 준다.

Pawn·Settlement의 native player faction은 바꾸지 않는다. 소속 때문에 식민지 조작을 NPC에 넘기거나 게임을 종료하는 코드를 추가하지 않았다. 퀘스트 관계 잠금·플레이어 전용 우호도 상한이 원본 관계와 충돌하면 공유를 중단한다. 종주 소실·내부 적대·계약 무효화도 같은 방식이며 마지막 관계/계약 기록은 보존한다. 문제 해결 후 같은 권위자의 유효성·동의를 다시 확인해야 재개한다. 중단 상태는 정상적인 독립 판정이 아니며 모든 관계를 가입 전으로 자동 복구하지 않는다. 다른 모드의 임의 관계 객체 직접 수정과 모든 퀘스트 경로의 호환성을 검증한 것은 아니다.

`PlayerAllegiance`는 고정 native player ID와 전환 명령을 버전 1 JSON으로 저장·재생한다. 기존 봉신 계약이 실제로 해약되기 전 다른 계약이나 연합으로 이중 편입하지 못한다. 연합에서 새 종주로 가려면 3일 전 통보, 서명된 새 계약, 미완료 물품 이전 해소가 필요하다. 통보를 다시 눌러 기간을 줄일 수 없다. 연합 회비는 아직 없으므로 이 확인은 미래의 모든 연합 의무 정산을 구현한 것이 아니다. NPC 영지의 제한된 수동 Faction 이동은 위 0.3.4 절에서 추가했다. 플레이어의 해약 후 자동 연합 가입과 정당한 일방 독립은 후속 작업이다.

추가 72개 순수 검사는 동의·기존 계약 해약·통보기간 경계·중단/재확인·저장 재생·손상 입력과 독립된 관계 스냅샷을 검증한다. 실제 게임의 창·Harmony 패치·외교 사건·일시정지·Scribe 재로딩·플레이어 통제는 실행 검증하지 않았다. **1단계 전체 완료나 Workshop 배포 가능한 검증판을 의미하지 않는다.**

### 1단계: 실제 NPC 자유도시연합 초기 배치 (0.3.2)

모드가 활성화된 세계를 처음 열면 **기존 세계 유지 / 초기 자유도시 구성**을 선택하는 창을 제시하도록 작성했다. 닫으면 선택을 미루고, 확정 전에는 소유권을 바꾸지 않는다. 선택은 저장 게임별로 기록한다. 플레이어 정착지의 **초기 정치 질서 설정** 명령으로 다시 열 수 있다. 새로운 행성 생성기 자체의 설정 화면/봉신 계층 생성기는 아직 아니며 시작/불러오기 이후에 동작하는 초기화 단계다.

기존 유지 선택은 도시 소속을 변경하지 않는다. 구성 선택은 적격 도시의 0~30%(기본 10%), 최대 10개·원 세력당 1개를 미리 표시하고 확정 후 실제 `Settlement.SetFaction`으로 하나의 `HonorContracts_FreeCityUnion` 세력에 편입한다. 같은 native faction에 속하므로 편입 NPC 도시들은 바닐라 대외 관계를 공유한다. 기존 도시의 개별 원 세력 외교 대신 연합 외교·기본 산업 기술 병력/거래·이념이 적용되며 이를 확정 전에 표시한다. 인물/맵별 문화·병종 보존은 후속 작업이다.

플레이어 세력, 로딩된 맵, 방문/재고 생성 또는 주민 생성 이력이 있는 도시, 계약 장부에 등록된 도시, 적대/영구 적대 세력, 숨김/임시/멸망 세력, 비인간형 세력, 왕실 작위 체계를 가진 세력, 원 세력의 마지막 정착지는 제외한다. 확정 직전에 실제 소유자·정착지 수·모든 조건을 재확인한다. 플레이어 기지나 Pawn의 faction은 변경하지 않으며, 봉신 영지를 `Faction.OfPlayer`로 바꿔 일반 플레이어 기지로 만들지도 않는다.

연합 FactionDef는 바닐라 OutlanderFactionBase를 상속하고 자동 세계 생성 수와 가중치는 0이다. 게임이 무작위 연합 정착지를 추가로 생성하지 않도록 `FactionGenerator.NewGeneratedFaction`의 hidden override를 사용한 뒤, 공개 faction으로 전환하고 manager에 등록한다. 동일 Def의 기존 세력이 있으면 재사용하며 중복/멸망 세력은 임의 복구하지 않는다. 이름·설명·시민/지도자 명칭은 영한 번역을 제공하고 연합 이름은 게임의 현재 언어로 표시한다.

`UnionAdmissionLedger`에 준비/적용/취소 시각과 원 소유자·목표 세력·도시 ID를 기록한다. 실제 참조는 `UnionCityReference`가 Scribe에 저장한다. 부분 실패를 전체 성공으로 기록하거나 저장 후 도시를 다시 이동시키지 않는다. 미완료 건은 현재 소유자가 연합인지/원 소유자인지 확인해 완료/취소할 수 있고, 제삼자가 점령했거나 맵이 로딩된 상태를 임의로 덮어쓰지 않는다. 이미 적용된 도시가 나중에 정복돼도 이 초기화 코드는 자동으로 되돌리지 않는다. 적용한 건이 있으면 두 번째 초기 재편을 막으며 전부 미이동 취소로 확인된 경우에는 재검토할 수 있다.

연합의 무작위 습격과 바닐라 군사 원조 요청은 비활성화했다. 평의회 의결 없이 임의로 연합 군사를 사용하는 기능을 완성했다고 표시하지 않는다. 플레이어 가입과 공유 외교는 위 0.3.3 절에서 추가했다. NPC 소속 변경은 위 0.3.4의 제한된 별도 집행을 사용한다. **일방 독립·평의회 표결은 아직 미연결이다.** 1단계 전체가 완료된 것은 아니다. FactionDef 실제 해석/세력 생성/도시 변경/팝업/저장 복원은 코드와 빌드만 검사했고 게임을 실행하지 않았다.

### 선택형 실제 공납 전달

계약 장부에서 플레이어가 봉신인 활성 계약에 **이 계약의 실제 공납 켜기**를 선택하면 켠 시점부터 공납 일정을 시작한다. 기존 개발용 계약에 소급 청구하지 않는다. 가입/서명만으로 물품을 자동 차감하지 않는다. 고정 원금 100, 봉신 직접 배송의 운송 몫 10% 공제에 따라 회차당 인수 가치 90을 요구한다. 주기 5일·유예 1일이며 미납 자체로 자동 명예 유죄나 전쟁을 만들지 않는다.

납기 후 종주 세력 정착지 타일에 플레이어 상단을 도착시키고 납부 버튼을 누른다. 협상 가능한 플레이어 상단원과 수령지의 실제 거래가격으로 일반 소지품을 평가하며 품목별 수량·단가·총액·반환하지 않는 초과 가치를 먼저 표시한다. **전달 확정은 실제 소지품을 NPC 정착지 거래 재고로 이전한다.** 따라서 별도 가상 모델의 배송 버튼과 효과가 다르다. 현재는 직접 배송만 지원하며 방문 징수·NPC의 상납은 아직 없다.

가격은 설치된 TradeUtility.GetPricePlayerSell/GetPricePlayerBuy와 TraderKind 가격형·협상가 능력·정착지 보정·약물/축산물 보정·게임 난이도·물품 상태에 따른 바닐라 계산을 사용한다. 은은 통화 물품의 시장가로 평가한다. 거래 화면의 전역 TradeSession을 덮어쓰지 않는다. 납부 직전에 소유권·외교·상단 위치·남은 수량·단가를 다시 확인한다. 현재 일반 Item 소지품만 취급하며 Pawn·시체·축소 건물/중첩 보관물은 제외한다. 호의 통화와 작위 제한 거래는 권한 연동 전까지 거절한다. NPC 공납을 지급하려고 자원을 새로 생성하지 않는다.

`TributeLedger`는 계정·날짜별 회차·준비/확정/취소 영수증을 별도 JSON으로 저장한다. `TributePaymentLedger`는 실제 수령지·상단·운반자·물품 참조와 ThingOwner 임시 보관을 Scribe로 저장한다. 모든 선택 물품을 임시 보관한 후 수령지에 옮기고, 각 물품의 실제 목적지·수량을 확인한 다음 영수증을 확정한다. 같은 회차는 준비 중에도 재납부할 수 없다. 초과 가치는 다른 의무를 갚지 않는다. 합의 해약은 새 청구를 중단하되 이전 납기 의무와 납부 기록을 유지한다.

중단 시 완료를 입증하면 영수증을 확정하고, 그렇지 않으면 확인 가능한 물품의 반환을 시도한다. 전량 반환을 확인해야 회차 예약을 해제한다. 행방/수량을 입증할 수 없는 부분 이전은 임시 보관과 기록을 보존하며 다시 납부하도록 자동 초기화하지 않는다. 미완료 이전이 있거나 결제 장부를 복원하지 못하면 해약도 보류한다. 임의의 모드 훅 예외·외부 재고 조작에서 항상 자동 복구된다는 보장은 없다.

한 계정 최대 1,200회차, 전체 영수증 4,000개, 납부당 최대 100개 스택을 취급한다. **이는 코드/빌드 단계 구현이다. 실제 상단 전달·가격 화면 대조·실물 보존·엔진 저장 재로딩은 아직 실행하지 않았다.** 보호 임무와 일반적인 영지 소속 이전은 미완성이므로 완성 계약 모드로 Workshop에 게시하지 않는다.

### 실제 정착지 계약 장부 (추가 개발)

월드 정착지 명령 **정착지 계약 장부 / Settlement charter records**에서 실제 정착지와 세력 참조를 등록한다. 가상 전쟁 모델과 별도의 장부다. 플레이어가 봉신이 되는 제안은 NPC **세력 전체**를 종주로 기록하고, 플레이어가 종주가 되는 제안은 선택한 NPC **정착지 하나**를 봉신으로 기록한다. 모든 플레이어 기지는 하나의 플레이어 정치 ID를 공유한다. 세력의 수도 하나가 없어져도 세력이 존속하면 세력 단위 종주 참조를 임의 소멸시키지 않는다.

`CharterBook`은 고정 문안·3일 응답 기한·NPC/플레이어 개별 동의 시각·합의 해약의 개별 동의를 저장한다. NPC 동의만으로 플레이어를 종속시키지 않는다. 최종 서명과 해약 때 현재 소유권·존재·외교 자격 및 연결된 계약 영지를 재검증한다. 소유권 변경/영지 소실/적대 전환은 동작을 보류하고 기존 기록은 남긴다. 중복 주군·순환·하위 집단을 포함한 4단계 한도도 최종 체결 때 다시 검사한다.

초기 NPC 협상은 실제 현재 세력 지도자와 바닐라 우호도를 사용한다. NPC가 종주가 되려면 우호도 0, 봉신이 되려면 50, 합의 해약에는 20 이상을 요구한다. UI에 기준을 공개했다. 이는 임시 협상 정책이며 명예/장기 실적/세력 규모에 따른 협상을 완성한 것이 아니다. 해약 거절 시 요청자의 동의만 남고 계약은 유지된다. 계약 문안은 가치 100/5일·유예 1일·봉신 배송 10% 운송 공제·병력 보호 응답으로 제한된다.

GameComponent가 실제 Settlement/Faction을 Scribe 참조로, 정치 장부를 별도 버전 1 JSON으로 보관한다. 잘못된 복원은 원본 데이터를 보존하고 동작을 막는다. 코드 검사에서 동의 순서·기한·실시간 소유권 변경·중복 관측·후손 유지·변조된 저장 거절을 검증했다. **실제 게임의 저장/재로딩은 실행하지 않았다.**

**활성 기록만으로 모든 계약 효과가 집행되지는 않는다.** 실제 공납은 선택형 직접 전달만 연결했다. 초기 NPC 자유도시 배치는 별도 확정 절차이며 제한된 NPC Faction 편입은 위 0.3.4 절에서 추가했다. 보호 퀘스트·명예 변화는 미연결이다. 플레이어 공유 외교는 별도의 검토·확정 절차를 거친다. 장부 서명만으로 NPC 도시를 자동으로 연합에 옮기지 않는다. 적격 NPC 도시의 합의 해약 후 연합 편입은 별도 검토·확정으로 적용한다. 가상 모델의 영수증·전투 결과를 실제 장부로 복사하지 않는다. 장부는 한 당사자가 플레이어인 계약만 취급하며 NPC끼리의 봉신 계층 생성은 후속 작업이다.

### 독립된 가상 모델

- 안정적인 정치 주체 ID와 native faction ID 분리. 플레이어 ID는 하나로 유지하며 주민·기지의 실제 소속을 수정하지 않는다.
- 직속 계약, 순환/중복 종속 금지, 최상위 포함 4단계. 하위 집단 전체를 포함해 이동 후 깊이를 검사한다. 최상위 대외 외교 그룹을 조회한다.
- 고정 가치 공납, 5일 주기/1일 유예 예제. 봉신 배송은 운송 몫 공제, 종주 방문 징수는 추가 비용. 원금·인수 가치 분리. 기한 이후 신뢰 하락은 한 번만 적용하며 자동 명예 유죄/전쟁/해약 없음.
- 전체 모델 영수증 중복 금지, 충분한 실제 거래가치가 전달됐다는 **어댑터 입력 규약**. 미리보기 버튼은 가상 영수증일 뿐 실제 거래가격 계산/물품 인수 검증이 아니다. 초과 납부가 다른 의무를 갚지 않는다.
- NPC 대상 공격 요청, 기한, 병력 예약, 동맹 구원, 가용 병력과 원정 병력의 중복 방지, 결과/손실/명예 한 번 반영. 모델 보호 조항은 기한 내 **병력 응답**만 인정한다. 다른 지원 방식과 면책은 추후 추가한다.
- 명시한 보호 조항 미이행 → 시정 통보 → 실제 시간 기한 → 미해결이면 정당한 독립. 낮은 명예만으로 독립 불가. 양측이 수락한 시정 합의로 독립 사유를 해소할 수 있다. 독립/합의 해약 시 하위 계약·과거 공납 기록 유지, 연합 그룹으로 이동.
- NPC 패배 결과는 기록하지만 소속 이전/점령 계약을 자동 생성하지 않는다. 기존 소유권/계약을 덮어쓰지 않는다. 플레이어 기지는 추상 공격의 패배 대상에서 제외한다.
- 설정된 간격으로 번영을 간략 갱신. 날짜 기한은 턴 간격과 별개. 큰 시간 도약도 중간 기한·턴을 순서대로 처리한다.
- 명령 재생 기반 버전 1 저장: 직렬화/복원 시 같은 검증 경로. 연속 시간 갱신 압축, 미래 스키마/손상 입력 거절. 게임 Scribe에는 JSON 문자열과 시계 연결 설정을 저장한다. 복원 실패 시 원본 문자열을 보존하고 모델을 중지한다.
- 영·한 keyed 문구와 placeholder 일치 검사. 현재 게임 언어를 따르고 언어 설정을 변경하지 않는다.

초기 모델 제한: 주체 최대 200, 명령 최대 10,000, 시간 전진 호출당 최대 120일, 전체 모델 6,000일, 턴 0.25~10일(화면 1~10일). 용병단/평의회/세계 생성/개인 서약/장기 경제를 구현한 것이 아니다. 화면의 초기 정착지·병력·전투 공식·번영 수치는 시험 데이터이며 확정 밸런스가 아니다. 인구/병종·장비별 충원·별도 공납 수송 상단은 아직 없다.

## 로컬 빌드와 선택형 설치

기존 `GamePaths.props`와 .NET 10 SDK 설정 후:

```powershell
./tools/Build.ps1 -DotnetPath '<local .NET 10 SDK>/dotnet.exe'
./tools/Install-ContractsPreview.ps1 -RimWorldDir '<RimWorld directory>'
```

설치기는 게임을 실행하거나 모드 활성 설정을 변경하지 않는다. 기존 동일 package ID 설치가 있으면 `.local`에 백업한다. 직접 확인할 때 게임 모드 목록에서 **Honor.Contracts — Development Preview**를 선택한다. 로드 순서는 Harmony 3 → Core 0.2.1+ → Preview. 다른 부속 모드/DLC는 필수 아님. 이후 사용자 요청 전까지 에이전트가 게임을 실행하지 않는다.

가상 모델의 향후 사용 경로(미실행): 월드맵에서 플레이어 정착지 선택 → 계약 개발 미리보기 → 모델 생성. 계약 합의 → 5일 경과 → 가상 배송 기록, 또는 가상 공격 → 구원 병력 파견 → 기한 경과 → 결과. 구원을 보내지 않았다면 시정 요구 → 합의 시정 또는 3일 대응 기간 뒤 독립. 이 가상 화면의 버튼은 모의 사건 입력이며 실제 전투 증거를 만들어 내지 않는다. 별도 정착지 계약 장부의 실물 공납은 위 설명대로 실제 소지품을 이전한다.
