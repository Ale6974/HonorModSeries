# Honor.Contracts 연결 흐름 개발 미리보기

## 용도와 상태

사용자가 선택한 전체 흐름 우선 개발의 첫 연결 버전이다. `PoliticalWorld`는 실제 Faction과 별개의 정치 주체 ID를 사용한다. `Honor.Contracts.Preview`는 **별도 선택형 개발 모드**이며 공개 Core/Society/Nobility/Diplomacy/Oaths에 자동으로 포함되지 않는다. 실제 플레이 증명 없이 완성 모드로 Workshop에 게시하지 않는다.

설치 게임 1.7.4985 rev1269의 Assembly-CSharp/UnityStubs/Waylith와 Harmony 3 RC DLL로 컴파일했다. 새 게임 실행·UI 조작·Scribe 게임 저장 재로딩은 수행하지 않았다. 빌드는 API 참조 검사이지 엔진 동작 증거가 아니다.

## 이번에 연결한 범위

### 선택형 실제 공납 전달

계약 장부에서 플레이어가 봉신인 활성 계약에 **이 계약의 실제 공납 켜기**를 선택하면 켠 시점부터 공납 일정을 시작한다. 기존 개발용 계약에 소급 청구하지 않는다. 가입/서명만으로 물품을 자동 차감하지 않는다. 고정 원금 100, 봉신 직접 배송의 운송 몫 10% 공제에 따라 회차당 인수 가치 90을 요구한다. 주기 5일·유예 1일이며 미납 자체로 자동 명예 유죄나 전쟁을 만들지 않는다.

납기 후 종주 세력 정착지 타일에 플레이어 상단을 도착시키고 납부 버튼을 누른다. 협상 가능한 플레이어 상단원과 수령지의 실제 거래가격으로 일반 소지품을 평가하며 품목별 수량·단가·총액·반환하지 않는 초과 가치를 먼저 표시한다. **전달 확정은 실제 소지품을 NPC 정착지 거래 재고로 이전한다.** 따라서 별도 가상 모델의 배송 버튼과 효과가 다르다. 현재는 직접 배송만 지원하며 방문 징수·NPC의 상납은 아직 없다.

가격은 설치된 TradeUtility.GetPricePlayerSell/GetPricePlayerBuy와 TraderKind 가격형·협상가 능력·정착지 보정·약물/축산물 보정·게임 난이도·물품 상태에 따른 바닐라 계산을 사용한다. 은은 통화 물품의 시장가로 평가한다. 거래 화면의 전역 TradeSession을 덮어쓰지 않는다. 납부 직전에 소유권·외교·상단 위치·남은 수량·단가를 다시 확인한다. 현재 일반 Item 소지품만 취급하며 Pawn·시체·축소 건물/중첩 보관물은 제외한다. 호의 통화와 작위 제한 거래는 권한 연동 전까지 거절한다. NPC 공납을 지급하려고 자원을 새로 생성하지 않는다.

`TributeLedger`는 계정·날짜별 회차·준비/확정/취소 영수증을 별도 JSON으로 저장한다. `TributePaymentLedger`는 실제 수령지·상단·운반자·물품 참조와 ThingOwner 임시 보관을 Scribe로 저장한다. 모든 선택 물품을 임시 보관한 후 수령지에 옮기고, 각 물품의 실제 목적지·수량을 확인한 다음 영수증을 확정한다. 같은 회차는 준비 중에도 재납부할 수 없다. 초과 가치는 다른 의무를 갚지 않는다. 합의 해약은 새 청구를 중단하되 이전 납기 의무와 납부 기록을 유지한다.

중단 시 완료를 입증하면 영수증을 확정하고, 그렇지 않으면 확인 가능한 물품의 반환을 시도한다. 전량 반환을 확인해야 회차 예약을 해제한다. 행방/수량을 입증할 수 없는 부분 이전은 임시 보관과 기록을 보존하며 다시 납부하도록 자동 초기화하지 않는다. 미완료 이전이 있거나 결제 장부를 복원하지 못하면 해약도 보류한다. 임의의 모드 훅 예외·외부 재고 조작에서 항상 자동 복구된다는 보장은 없다.

한 계정 최대 1,200회차, 전체 영수증 4,000개, 납부당 최대 100개 스택을 취급한다. **이는 코드/빌드 단계 구현이다. 실제 상단 전달·가격 화면 대조·실물 보존·엔진 저장 재로딩은 아직 실행하지 않았다.** 보호 임무·세력 편입·공유 외교는 여전히 미연결이므로 완성 계약 모드로 Workshop에 게시하지 않는다.

### 실제 정착지 계약 장부 (추가 개발)

월드 정착지 명령 **정착지 계약 장부 / Settlement charter records**에서 실제 정착지와 세력 참조를 등록한다. 가상 전쟁 모델과 별도의 장부다. 플레이어가 봉신이 되는 제안은 NPC **세력 전체**를 종주로 기록하고, 플레이어가 종주가 되는 제안은 선택한 NPC **정착지 하나**를 봉신으로 기록한다. 모든 플레이어 기지는 하나의 플레이어 정치 ID를 공유한다. 세력의 수도 하나가 없어져도 세력이 존속하면 세력 단위 종주 참조를 임의 소멸시키지 않는다.

`CharterBook`은 고정 문안·3일 응답 기한·NPC/플레이어 개별 동의 시각·합의 해약의 개별 동의를 저장한다. NPC 동의만으로 플레이어를 종속시키지 않는다. 최종 서명과 해약 때 현재 소유권·존재·외교 자격 및 연결된 계약 영지를 재검증한다. 소유권 변경/영지 소실/적대 전환은 동작을 보류하고 기존 기록은 남긴다. 중복 주군·순환·하위 집단을 포함한 4단계 한도도 최종 체결 때 다시 검사한다.

초기 NPC 협상은 실제 현재 세력 지도자와 바닐라 우호도를 사용한다. NPC가 종주가 되려면 우호도 0, 봉신이 되려면 50, 합의 해약에는 20 이상을 요구한다. UI에 기준을 공개했다. 이는 임시 협상 정책이며 명예/장기 실적/세력 규모에 따른 협상을 완성한 것이 아니다. 해약 거절 시 요청자의 동의만 남고 계약은 유지된다. 계약 문안은 가치 100/5일·유예 1일·봉신 배송 10% 운송 공제·병력 보호 응답으로 제한된다.

GameComponent가 실제 Settlement/Faction을 Scribe 참조로, 정치 장부를 별도 버전 1 JSON으로 보관한다. 잘못된 복원은 원본 데이터를 보존하고 동작을 막는다. 코드 검사에서 동의 순서·기한·실시간 소유권 변경·중복 관측·후손 유지·변조된 저장 거절을 검증했다. **실제 게임의 저장/재로딩은 실행하지 않았다.**

**활성 기록만으로 모든 계약 효과가 집행되지는 않는다.** 실제 공납은 위 선택형 직접 전달만 연결했으며 Faction 편입·연합 외교·보호 퀘스트·명예 변화는 미연결이다. 장부는 최초 세계 재편이나 NPC 도시를 자동으로 자유도시연합으로 옮기지 않는다. 종료 후 연합 편입도 현재 실제 게임에는 적용하지 않는다. 가상 모델의 영수증·전투 결과를 이 장부로 복사하지 않는다. 현재 장부는 한 당사자가 플레이어인 계약만 취급하며 NPC끼리의 초기 정치 질서 생성은 후속 작업이다.

### 독립된 가상 모델

- 안정적인 정치 주체 ID와 native faction ID 분리. 플레이어 ID는 하나로 유지하며 주민·기지의 실제 소속을 수정하지 않는다.
- 직속 계약, 순환/중복 종속 금지, 최상위 포함 4단계. 하위 집단 전체를 포함해 이동 후 깊이를 검사한다. 최상위 대외 외교 그룹을 조회한다.
- 고정 가치 공납, 5일 주기/1일 유예 예제. 봉신 배송은 운송 몫 공제, 종주 방문 징수는 추가 비용. 원금·인수 가치 분리. 기한 이후 신뢰 하락은 한 번만 적용하며 자동 명예 유죄/전쟁/해약 없음.
- 전체 모델 영수증 중복 금지, 충분한 실제 거래가치가 전달됐다는 **어댑터 입력 규약**. 미리보기 버튼은 가상 영수증일 뿐 실제 거래가격 계산/물품 인수 검증이 아니다. 초과 납부가 다른 의무를 갚지 않는다.
- NPC 대상 공격 요청, 기한, 병력 예약, 동맹 구원, 가용 병력과 원정 병력의 중복 방지, 결과/손실/명예 한 번 반영. 모델 보호 조항은 기한 내 **병력 응답**만 인정한다. 다른 지원 방식과 면책은 추후 추가한다.
- 명시한 보호 조항 미이행 → 시정 통보 → 실제 시간 기한 → 미해결이면 정당한 독립. 낮은 명예만으로 독립 불가. 양측이 수락한 시정 합의로 독립 사유를 해소할 수 있다. 독립/합의 해약 시 하위 계약·과거 공납 기록 유지, 연합 그룹으로 이동.
- NPC 패배 결과는 기록하지만 소속 이전/점령 계약을 자동 생성하지 않는다. 기존 소유권/계약을 덮어쓰지 않는다. 플레이어 기지는 추상 공격의 패배 대상에서 제외한다.
- 설정된 간격으로 번영을 간략 갱신. 날짜 기한은 턴 간격과 별개. 큰 시간 도약도 중간 기한·턴을 순서대로 처리한다.
- 명령 재생 기반 버전 1 저장: 직렬화/복원 시 같은 검증 경로. 연속 시간 갱신 압축, 미래 스키마/손상 입력 거절. 게임 Scribe에는 JSON 문자열과 시계 연결 설정을 저장한다. 복원 실패 시 원본 문자열을 보존하고 모델을 중지한다.
- 영·한 keyed 문구와 placeholder 일치 검사. 현재 게임 언어를 따르고 언어 설정을 변경하지 않는다.

초기 모델 제한: 주체 최대 200, 명령 최대 10,000, 시간 전진 호출당 최대 120일, 전체 모델 6,000일, 턴 0.25~10일(화면 1~10일). 용병단/평의회/세계 생성/개인 서약/장기 경제를 구현한 것이 아니다. 화면의 초기 정착지·병력·전투 공식·번영 수치는 시험 데이터이며 확정 밸런스가 아니다. 인구/병종·장비별 충원·별도 공납 수송 상단은 아직 없다.

## 로컬 빌드와 선택형 설치

기존 `GamePaths.props`와 .NET 10 SDK 설정 후:

```powershell
./tools/Build.ps1 -DotnetPath '<local .NET 10 SDK>/dotnet.exe'
./tools/Install-ContractsPreview.ps1 -RimWorldDir '<RimWorld directory>'
```

설치기는 게임을 실행하거나 모드 활성 설정을 변경하지 않는다. 기존 동일 package ID 설치가 있으면 `.local`에 백업한다. 직접 확인할 때 게임 모드 목록에서 **Honor.Contracts — Development Preview**를 선택한다. 로드 순서는 Harmony 3 → Core 0.2.1+ → Preview. 다른 부속 모드/DLC는 필수 아님. 이후 사용자 요청 전까지 에이전트가 게임을 실행하지 않는다.

가상 모델의 향후 사용 경로(미실행): 월드맵에서 플레이어 정착지 선택 → 계약 개발 미리보기 → 모델 생성. 계약 합의 → 5일 경과 → 가상 배송 기록, 또는 가상 공격 → 구원 병력 파견 → 기한 경과 → 결과. 구원을 보내지 않았다면 시정 요구 → 합의 시정 또는 3일 대응 기간 뒤 독립. 이 가상 화면의 버튼은 모의 사건 입력이며 실제 전투 증거를 만들어 내지 않는다. 별도 정착지 계약 장부의 실물 공납은 위 설명대로 실제 소지품을 이전한다.

## 다음 연결 작업

세력 소속 반영/플레이어 특례, 방문 징수·NPC 상납·수송 상단 사건, 실제 퀘스트/전투 결과 증거, 항복·점령의 정착지 보존, 게임 세계 사건 생성과 알림, 이행 면책·반복 미납 제재, 평의회 가중 표결, 세계 생성/기존 저장 선택, 용병단과 개인 서약을 순차적으로 연결한다. 실제 정착지 매핑·동의 기록·직접 실물 공납 코드는 추가했지만 복잡한 NPC 권한·정치 판단·초기 세계 전체 적용은 아직 미완성이다. 기존 규칙의 RescuePledge/FactionHonorLedger와 새 모델 통합도 남아 있다. 현재 명예 수치는 Core Need/바닐라 우호도에 전파하지 않는다.

English: An opt-in, code-validated development preview. The separate fictional model does not affect real inventory. The live charter book now offers explicit opt-in manual tribute from a caravan at a counterparty settlement, moving real inventory into vanilla NPC stock with saved escrow and receipts. No automatic collection, incoming NPC tribute, title/favor trading, protection missions, sovereignty changes or player defeat simulation are provided. No gameplay validation or Workshop release is claimed.
