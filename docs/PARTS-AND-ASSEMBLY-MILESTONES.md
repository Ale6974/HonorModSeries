## 3층 구조

1. **공통 부품**: 한 가지 보존·권한·호출·저장 책임을 갖는 실제 구현. 입력/출력/오류/포맷/버전/중단 상태가 명시된 호출 가능한 API를 제공한다. 순수 규칙 부품과 native 어댑터를 구분한다.
2. **기능 조립**: M2 이전, M7 귀환, M8 합병 같은 사용처가 공통 부품을 연결하고 자신의 실제 UI/사건→적용→저장→명시 복구를 제공한다. 기능별 정책/조정기는 서로 다를 수 있다.
3. **통합 완료 검사**: 조립한 기능이 원 주민·재산·계약/채무·제삼자 권리를 보존하고 부분 처리/실패·옛 저장·영한/양 타깃 기준을 충족하는지 확인한다.

부품 검증 완료는 실제 기능 완료와 다르다. callable API·부품 검사·저장 fixture가 준비됐지만 사용처가 아직 없을 수 있다. 이때 ‘부품 완료, M7 미조립’이라고 보고하며 M7 실제 기능/단계 완료 점수를 부여하지 않는다. 진단/가드/규칙 모델만으로 실제 기능 완료를 판정하지 않는 기존 조건은 유지한다.

## 부품 계약과 완료 기준

각 부품은 다음 카드를 가진다.

- 소유 파일·API와 담당 마일스톤, 실제 재사용처
- 입력: 원 객체/ID·현재 소유자·원 증거·행동별 현재 권한
- 출력: 준비된 계획 또는 해당 호출의 양성 결과/명확한 보류 사유
- 변경 허용 범위: 이 부품이 실제로 바꿀 수 있는 것과 caller만 결정할 정책
- 저장 필드/버전/원 참조·다른 journal과의 짝·용량 한계
- 정상/부분 처리/중단/unknown call/원 객체 변경의 처리
- 재사용 검증 fixture와 양 타깃 컴파일/native API 근거

부품 상태: 설계→구현 중→부품 검증 완료. 사용처 상태: 미조립→부분 조립→실제 실행 연결→저장/복구 통합 완료→완료 감사 통과. JSON의 part_evidence/assembly_evidence/integration_evidence에 실제 파일·입출력·저장/복구 진입점·검사 근거를 기록한다. 현재 빈 목록은 해당 새 부품 계약에 대해 재검수하지 않았다는 뜻이며 기존 구현을 삭제/미구현으로 재분류한 것이 아니다.

## M2에서 만든 것을 M7에서 조립하는 예

- M2에서 B01 원 주민/물체 식별, B02 임상·의료, B03 호출 기록, B04 현재 승인, B07 보관 계층을 준비하고 ‘도시 이전’ 조정기에 연결한다.
- M7은 B10으로 원 소실/귀환의 실제 사실을 수집하고 B11로 계약·후손·채무 정리 계획을 만든다. 귀환한 같은 원 객체를 이어서 처리해야 하면 B01/B02/B03/B04/B07을 다시 호출해 ‘귀환 후 재개’ 조정기를 조립한다.
- M7 고유 코드는 소실의 법적 의미·생존 후손·현재 재계약/재개 순서다. 기존 의료 복구나 물품 슬롯 처리 코드를 복사하지 않는다.
- 재사용하는 것은 **코드와 계약**이다. 다른 사건의 옛 승인·원 임상 snapshot·정상 반환 영수증을 새 사건의 허가로 복사하지 않는다. 새 행동은 자신의 원 범위·현재 동의·journal을 가진다. 같은 원 중단 실행을 재개할 때만 정확히 짝이 맞는 기존 양성 사실을 이어간다.
- 원 객체가 확정 파괴됐다면 재생성해 같은 것으로 간주하지 않는다. M2의 물리 사실 분류와 M7의 계약/채무 후속 정리를 연결한다.

## 진행도와 코드량

- 소유 마일스톤에서 부품 구현량을 한 번만 계산한다. M7 등이 재사용하면 조정기·연결·새 정책과 교차 검사 차이만 계산한다.
- 기존 추정은 이미 공통 기반 최초 구현/후속 연결 차이를 분리했으므로 이 운영 방식만으로38,650~78,000줄을 임의로 줄이거나 늘리지 않는다. 실제 분리/조립 결과가 나오면 각 항목의 잔여 범위를 갱신한다.
- 기능 전체 미완료여도 부품과 조립의 완료 근거를 각각 보여준다. 전체 단계는 원 완료 조건을 통과해야 완료다. 기존 M1 10/10·M2 0/18은 오늘 자동 환산하지 않는다. 세부 구조/운영 방식은 확정하지만 실제 점수는 검수 근거가 있어야 부여한다.
- 보고 형식: ‘이번 완성 부품 / 실제 조립 사용처 / 통합 확인 / 미조립 재사용처 / 남은 코드량’. 버전·줄 수·테스트 수만으로 진행률을 올리지 않는다.
