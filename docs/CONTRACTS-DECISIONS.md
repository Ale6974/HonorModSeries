# Contracts — 확정 결정 기록 (2026-10-24)

이 문서는 순차 질의로 확정한 사용자 선택이다. **구현 완료 목록이 아니다.** 초기 CONTRACTS-DESIGN의 상충 내용보다 우선한다. 코드·빌드·규칙 검사만 수행하고 실제 플레이 증명은 사용자 요청까지 미룬다. 개발 순서는 좁은 기능 완성보다 계약 → 공납 → 공격/구원 → 이탈 전체 흐름을 먼저 연결한다.

## 소속·계층·승계

- 자유도시·독립영지는 하나의 자유도시연합 세력에 속하며 대외 외교를 공유한다. 봉신 영지는 종주의 소속 세력으로 편입한다. 계약 당사자인 영지/정치 주체의 ID와 실제 게임 Faction ID는 분리해야 한다.
- 플레이어는 모든 정착지가 같은 정치적 소속을 공유하되 native player faction·주민/건설/전투 지휘를 유지한다. 가입·항복 때문에 게임이 끝나지 않는다. 도시별 공납·자치권은 다를 수 있다.
- 하위 봉신 허용. 최상위 포함 최대 4단계. 순환 금지. 각 단계는 직속 상대와 의무를 이행한다. 상위 종주의 직접 징발은 별도 계약 권한 필요. 최상위 세력의 전쟁·화평을 공유한다.
- 중간 봉신의 이동에 하위 봉신 계약도 함께 이동한다. 권리 침해에는 시정/해지 요구가 가능하며 새 계층이 4단계를 넘으면 편입 전 조정한다.
- 영지 계약과 개인 봉신 서약은 후계자에 자동 승계. NPC는 기존 지도자 선정 체계를 쓰고 플레이어는 개인 서약 후계자를 지정한다. 실적·미납·위반을 초기화하지 않는다.
- 마지막 영지 상실 시 해당 영지 계약은 종료하지만 생존자의 개인 서약은 유지한다. 망명·복구 요청 사건 가능.
- 새 플레이어 정착지는 소속·보호 자동 적용. 공납/병력은 개척 유예 후 별도 합의. 세계 생성 시 일부 기존 봉신 관계/자유도시를 설정 비율로 배치. 기존 저장 첫 로드에서는 기존 유지/정치 질서 재편을 선택한다.

## 도시 주민 이전의 보존 정책 (2026-10-25 확정)

- 주민이 있는 도시의 소속 이전은 주민의 정체성·건강·장비·관계와 의료 설정·수술 지시를 보존하는 것을 원칙으로 구현한다. 현재 작업·예약의 종료는 허용한다.
- 포로·노예도 도시와 함께 이전하되 신분을 유지하고 관리 주체만 새 도시 소속으로 변경한다. 포로의 원래 소속과 포로 신분, 노예 신분을 보존하며 소속 변경만으로 자동 석방/해방하거나 일반 주민으로 전환하지 않는다. 안전하게 보존할 수 없으면 해당 도시 이전을 보류한다. 이는 정책 확정이며 포로/노예 이전 구현 완료가 아니다.
- 이전 대상 주민 중 기존 세력 지도자가 있으면 별도 동의를 받아 새 소속으로 합류할 수 있도록 구현한다. 원래 세력은 후임 지도자를 선정한다. 지도자 합류의 동의 실패, 마지막 도시와 원 세력 존속, 후임 부재에 대한 세부 방침은 아직 미확정이며 이 결정만으로 강제 편입/자동 세력 소멸을 허용하지 않는다.
- 보존할 수 없는 상태가 있으면 해당 도시 이전을 보류하고 구체적인 이유를 안내한다. 이 선택은 정신 상태의 임의 치유·초기화, 주민 재생성이나 바닐라 상태 처리 우회를 허용하는 것이 아니다.
- 네이티브 소속 변경이 초기화하는 상태는 사전 검사와 명시적 복원/사후 검증이 필요하다. 보존 구현과 복구가 마련되기 전에는 기존 주민 이전 차단을 유지한다. 이는 확정 정책이며 구현/플레이 검증 완료가 아니다.

## 영향력·외교·이탈

- 봉건 세력은 종주 최종 결정·성향 중심, 연합은 이해관계와 평의회 표결. NPC 판단 이유를 표시한다.
- 계약 의무 이행 실적·명예·관계가 영향력 근거. 규모도 반영하되 큰 세력의 낮은 기여에는 발언권 상한. 제안/의견 권리 자체는 박탈하지 않는다.
- 실적은 현재 계약 전체 기간, 동일 상대 갱신 시 성공/미이행 모두 승계. 다른 상대와의 계약 규모/실적은 명예로 간접 반영한다.
- 연합 전쟁·화평 모두 전체 가중 표의 과반수, 동률 부결. 피습 시 적대 상태 공유, 공동 출병/자금은 긴급 표결. 부결되어도 개별 자발 지원 허용.
- 가결된 공동 부담은 기존 약정 초과 가능. 도시별 배정·기한을 표결 전에 공개. 피해/인력 부족은 감면·대체 이행 요청 가능.
- 연합 탈퇴는 사전 통보·확정 의무 정산 후 새 종주 계약 발효와 연결. 새 계약 전까지 연합 소속 유지. 별도 무소속 세력을 만들지 않는다.
- 플레이 중 여러 세력이 종주가 되겠다는 제안을 보낸다. 기존 종주가 있어도 이적 제안 가능; 검토만으로 위반 아님.
- 종주 위반이 없다면 합의 해약. 무단 이탈은 복귀/배상 요구 → 협상 → 가능한 전쟁의 단계적 대응.
- 정당한 독립은 중대한 종주 위반 + 시정 요구 + 기한 내 미해결 필요. 낮은 명예만으로 정당화 불가. 독립 영지와 하위 봉신은 연합으로 이동한다.
- 세력 명예는 사건 기반 비화폐 지표, 계약 양방향 신뢰와 이탈 압박에 영향. 개인 Need·바닐라 관계/기억은 유지한다.

## 공납·내정·전쟁

- 공납은 약정한 **고정 가치**, 실제 거래가격으로 납부 물품 평가. 정착지 성장만으로 자동 인상 불가. 실적은 의무별 100% 상한, 초과 성과는 명예/관계. 다른 미이행 자동 상쇄 금지.
- 방문 징수/직접 운송을 계약에서 정한다. 플레이어가 납세자이면 방문 징수 수수료 추가. 플레이어가 종주이면 직접 징수 전액, 봉신 배송에는 운송 몫 공제. 운송 담당자가 손실 부담. 정상 습격 피해 자체는 불명예 아님; 유예/감면 요청 가능.
- 미납: 독촉·유예 → 미납/신뢰 하락 → 반복/장기화 시 위반/제재 협상. 자동 즉시 전쟁 금지.
- NPC 내정은 정책 지시. 매 월드 턴 번영·인구 규모·방어력 간략 계산, 공납·전쟁·투자 반영. 공납 원금은 재협상까지 고정.
- 계약 밖 부담은 협상 또는 강권. 정당한 거부를 봉신 위반으로 보지 않는다. 강권 불응 시 제재/무력 집행과 굴복/저항; 즉시 자원 강탈 아님. 권리 침해는 종주의 위반 근거.
- 보호 범위·인정 지원 수단은 계약별. 직속 종주 우선, 부족하면 상위 계약에 따라 지원 요청. 상위 자동 출병 의무 없음.
- NPC 전쟁은 월드 사건 턴 방식. 기본 게임 내 1일, 설정 변경 가능. 주요 결정 일시정지/알림. 실제 날짜 기한을 표시한다.
- NPC끼리도 함락·소속 변경·항복/점령 계약 발생. 플레이어 기지 패배는 실제 전투로만 판정. 전투 중 선택적 항복 협상, 수락 전 조건 표시, 이후 실적/명예/관계에 따른 재협상 가능.
- 영지별 병력 규모·숙련·장비·손실 지속 관리. 파견 병력의 방어 중복 금지. 충원/훈련/장비 회복은 시간·자원 필요. 작전 목표 지시 → 월드 턴 진행, 직접 참여 전투의 지원군은 플레이어 지휘.
- 분쟁은 봉건 종주/연합 평의회 중재. 당사자 직접 결투 원칙, 계약/작위 예외만 대리. 결투는 사전 합의 쟁점에만 구속력. 불이행은 중재 기관 집행. 종주 자신이 당사자면 합의한 제삼자 중재.

## 병력 지원·용병단

- 인력 지원은 임무 기간 후 귀환하는 추상 파견, 직접 수행만 실제 전투 지휘. 필수/권장 자격·병력수 상한·능력/장비 효과·실패 실적 기준을 요청별로 공개한다. 초과 목표·관련 매복/야영지 처리의 초과 성과는 명예/관계.
- 개인 장비 지참. 부상/장비 손실 위험 각각 사전 명시. 자동 사망 없음; 포로/부상 가능, 영구 손상은 명시된 고위험만. 기간 종료 시 출혈 등 상처는 치료/안정화 후 복귀, 완전 회복까지 대기 아님. 직접 전투의 실제 사망은 가능.
- 일반 인력 지원 중도 소환 불가. 고용 용병단의 계약 해지 철수는 별도 예외. 포로는 구출/몸값 후속 사건. 성공적인 구출 시 압수 장비도 자동 반환.
- 부상·포로·사망·장비 손실 자동 보상 없음. 제공 측 구원 의무는 별도 계약 조항.
- 여러 세력이 용병단 제공, 고급 병과는 더 엄격한 자격 조건(예: Royalty가 있을 때 제국 강습대). 고용은 개인이 아닌 **용병단 계약**. 세력과 병과별 명예/관계/실적 조건.
- 용병은 직접 지휘/방어 및 허용된 지원 파견 대체 가능. 동일 자격/성과는 동일 실적. 임금과 병력 지원을 이중 기여로 세지 않는다.
- 시작금 + 종료금. 마지막 날 연장/종료를 일시정지로 선택, 자동 갱신 없음. 파견이 만료를 넘으면 출발 시 귀환일까지 연장·추가 비용 명시 합의.
- 포로가 되어도 원래 계약금액 유지, 포로 기간 때문에 추가 요금 없음. 구원 조항이 있는 계약만 방치에 명예/관계 불이익. 종료 후 책임 유지 여부도 계약별. 노력·기한·몸값 한도·면책을 공개, 사건당 평가 제한.
- 몸값은 고용주가 약정한 최소~최대 범위(최대는 계약금 제한) 부담, 나머지 용병 측 부담. 부족하면 재협상/구출 또는 자발 대납. 대납은 합의한 추가 복무/금전 상환/면제 선택. 의무 이행 후 대납 거부 자체는 불명예 아님.
- 전사: 시작금 유지, 종료금 복무 기간 비례. 고용주 해지: 시작금 반환 없음, 종료금 비례, 위약금 없음. 용병 측 해지: 미복무분 시작금 반환, 종료금 비례.
- 파견/포로 중에도 즉시 해지 가능. 파견 임무 중단·귀환 시간 필요, 중단 시점 성과 정산. 기존 포로 구원 책임은 종료 후 조항에 따름.
- 출신 세력과 싸울 때 계약·고용주 명예·기간 중 성과를 종합해 용병이 수락/거절, 사전 결과 표시. 거절 시 철수. 직접 선전포고/자발적 신규 참전은 고용주 해지, 제공 세력의 선전포고는 용병 해지. 기존 연합/종주 전쟁은 고지한 계약상 예외에 따라 정상 종료(미복무 시작금 반환·종료금 비례·양측 명예 불이익 없음).
- 전투 중 철수 시 신규 공격 제한, 자위/구조/퇴각 허용하며 안전한 이탈 시도. 용병 원장비/선물은 용병 소유, 대여 장비는 반환. 정상 임무 손실은 고용주 부담.
- 세부 조건 선택을 남발하지 않고 합리적인 자동 처리 + 드문 의미 있는 사건. 장비 도주·선수금 사기·매수/이탈·의리를 지킨 용병 등. 위험 징후·업체별 위험 차이·빈도 제한, 자동 기지 내 총격 배신 금지.
- 용병단 위반에는 소속 세력의 조사·회수·처벌 의무. 비호/방치하면 세력 명예·관계 하락. **소속 세력이 회수 불능액을 자동 대납하지는 않는다.**

## 구현 기록을 읽는 기준

초기 ContractTerms/FreeCityRules/RescuePledge는 구 모델의 엔진 독립 프로토콜이다. 어댑터와의 통합 전에는 실제 효과를 보장하지 않는다. 별도 가상 모델은 실제 세력/물품/전투를 바꾸지 않는다. 반면 개발 미리보기의 실물 공납과 초기 NPC 자유도시 구성은 각각 명시적으로 활성화/확정하면 실제 물품·세력 소속을 바꾸는 코드다. 현재 범위와 미구현은 CONTRACTS-PREVIEW/CONTRACTS-ROADMAP을 기준으로 읽는다. 가상 모델의 구원 완료 버튼은 실제 전투 증거가 아니다. 신규 기능의 직접 플레이 검증은 보류 중이다.
