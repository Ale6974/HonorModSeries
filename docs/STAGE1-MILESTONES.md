## 진행도 계산

2026-10-29 부분 구현: Preview0.3.67은 실제 주민 개인 서약 생성·후계 지정·자동/명시적 승계와 Scribe/JSON 복원을 연결했다. 영지 채무·실적은 원 장부에 그대로 두며 개인 의무 집행·NPC 개인 계층 전체·생존 지도자 면직과 소속 불일치의 일반 복구는 남아 있다. M1 전체 조건 미충족으로 점수는 그대로 0/10이다.

- 이전에 사용한 전체 1단계 잔여 35%는 **대략적 노력 추정**이다. 새 체크리스트의 0/100은 이미 구현된 기능이 없다는 뜻이 아니라 **이 기준일 이후 남은 작업의 완료 점수**가 0이라는 뜻이다.
- 아래 9개 작업군의 가중치는 남은 작업량을 기준으로 한 계획용 추정치이며 합계 100점이다. 세부 작업의 크기가 같다고 가정하지 않는다.
- 각 세부 항목은 완료 증거가 검토될 때만 체크한다. 작업군 점수는 해당 작업군의 모든 완료 조건을 충족할 때만 그 가중치 전체를 부여한다. 부분 구현은 진행 상태에 설명하되 점수는 0점이다. 따라서 전체가 완료되기 전이라도 계단식으로 증가하며 부분 진척을 숨기지 않도록 별도로 기록한다.
- 남은 작업 점수 = 완료된 작업군 가중치 합 / 100. 참고용 전체 단계 추정 = 65 + 35 × 완료 가중치 합 / 100 (%). 이는 65%를 코드로 측정했다는 뜻이 아니며 일정이나 실제 작업시간을 보장하지 않는다. 범위/복잡성이 실제로 달라지면 사유를 기록하고 추정치를 재평가한다.
- 100점은 9개 작업군의 실제 집행과 공통 완료 조건이 모두 충족된 경우에만 가능하다. 누락된 기능을 범위에서 빼거나 기존 제한을 제거하는 것만으로 점수를 얻지 않는다.
