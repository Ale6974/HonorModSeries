# Contracts 6단계 개발 순서

사용자가 2026-10-24에 동의한 단계별 진행 기록이다. 단계별 완료는 실제 통합 범위를 기준으로 판단하며, 순수 규칙·컴파일 통과만으로 플레이 검증을 완료했다고 하지 않는다. 직접 플레이 증명은 사용자 요청까지 보류한다.

| 단계 | 완료 기준 | 현재 상태 |
|---|---|---|
| 1. 계약·정치 구조 | 장부·4단계 계층·연합·소속/외교·가입/이적/독립을 실제 세계에 연결하고 플레이어 통제 유지 | **진행 중.** 계약·연합·관리청·외교, 해약 후 연합 복귀/새 종주 소속과 직속 NPC 봉신 이동의 통합 검토·단계별 복구를 작성. 일반 거래 물품만 있는 방문 도시의 보존 검사·이전 및 주민/재고 점검과 선택형 주민 기준 기록 저장·비교 추가. 로딩된 맵·주민/특수 재고 도시·전시 이적·일방 독립·NPC 계층 생성/다단계 후손 집행은 남음. 게임 실행 검증 보류 |
| 2. 영지·공납·의무 | 영지 변화와 공납/징수/운송/군사·보호 의무가 실제 자원과 성과로 연결 | 직접 실물 공납만 선행 연결. 징수관·NPC 상납·영지 경제/의무 통합은 남음 |
| 3. 전쟁·항복·구원 | 월드 턴 전쟁·포위·함락과 실제 전투 개입이 계약·소속·병력에 반영 | 독립 가상 모델/초기 규칙만 존재. 실제 전투·NPC 점령·구원 연결은 남음 |
| 4. 명예·정치·분쟁 | 세력 명예·신뢰·영향력·표결·강권·중재/결투가 정치 결과와 연결 | 순수 규칙/명세 중심. 실제 사건 자동 반영과 의결은 남음 |
| 5. 용병단·개인 봉신 | 고용·파견·정산·포로/몸값·배신 및 개인 서약/승계가 통합 | 사용자 결정 명세 있음. 게임 구현은 남음 |
| 6. 통합·배포 | 초기 세계/기존 저장·언어·설정·호환성·성능·설치/의존성 정리 후 검증 범위에 맞게 공개 | EN/KO, 1.6/1.7 분리 빌드·공용 데이터·로컬 묶음·Contracts 커버 추가, GitHub 소스 게시 진행. Contracts Workshop 공개와 실제 엔진 종합 검증은 보류 |

개발은 전체 흐름 우선 방식을 유지한다. 1~4단계의 최소 흐름을 연결하며, 구조가 안정된 뒤 상세 기능과 5단계 확장을 붙인다. 기존 다섯 Honor 모드의 검증·배포 이력을 신규 Contracts의 완료 증거로 사용하지 않는다. 최종 배포 계획은 기존 5개 + Honor.Contracts의 **6개 모드**이며 Preview는 별도 정식 모드로 더하지 않는다.

현재 상세 구현 범위와 제한은 [CONTRACTS-PREVIEW](CONTRACTS-PREVIEW.md), 확정 규칙은 [CONTRACTS-DECISIONS](CONTRACTS-DECISIONS.md)를 참조한다.
