# Contracts 6단계 개발 순서

사용자가 2026-10-24에 동의한 단계별 진행 기록이다. 단계별 완료는 실제 통합 범위를 기준으로 판단하며, 순수 규칙·컴파일 통과만으로 플레이 검증을 완료했다고 하지 않는다. 직접 플레이 증명은 사용자 요청까지 보류한다.

| 단계 | 완료 기준 | 현재 상태 |
|---|---|---|
| 1. 계약·정치 구조 | 장부·4단계 계층·연합·소속/외교·가입/이적/독립을 실제 세계에 연결하고 플레이어 통제 유지 | **진행 중.** 계약·연합·관리청·외교와 전체 NPC 후손 소속 이전의 통합 검토/복구, NPC 초기 내부 계층·동일 세력 하위 재배치/직속 복귀, 기본 모집 상담 기록·등록된 개종 목표/일반 이념을 가진 적격 포로의 관리 세력 변경·원 소속/신분/신앙·관찰한 초기화 값 복원/복구와 손님/소속 이념 알림 검사·도시별 보류 이유, 원 소속·직위를 유지하는 적격 지도자의 저장 참조 전출 협의/집행/복구, 역할 없는 적격 일반 이념 신도 보존, 제한된 일반 주민 집행·의료/미시작 표준 수술 지시 원본 복원/복구, 하위 전체 합의 해약·연합 이주/복구, 실제 파괴된 적격 말단 영지 계약 종료, 일반 물품/제한된 거래 동물 보존, 합의 해약한 옛 종주에 한정한 적대 출발지 이전을 작성. 로딩된 맵·진행/자원 결박/특수 수술/미지원 포로/노예/지도자 개인 합류·승계/특수 주민·인간/복잡 재고, 일반 전시 이적·정당한 일방 독립·상위/점령/진행 중 영지 소실 정리는 남음. 게임 실행 검증 보류 |
| 2. 영지·공납·의무 | 영지 변화와 공납/징수/운송/군사·보호 의무가 실제 자원과 성과로 연결 | 직접 실물 공납만 선행 연결. 징수관·NPC 상납·영지 경제/의무 통합은 남음 |
| 3. 전쟁·항복·구원 | 월드 턴 전쟁·포위·함락과 실제 전투 개입이 계약·소속·병력에 반영 | 독립 가상 모델/초기 규칙만 존재. 실제 전투·NPC 점령·구원 연결은 남음 |
| 4. 명예·정치·분쟁 | 세력 명예·신뢰·영향력·표결·강권·중재/결투가 정치 결과와 연결 | 순수 규칙/명세 중심. 실제 사건 자동 반영과 의결은 남음 |
| 5. 용병단·개인 봉신 | 고용·파견·정산·포로/몸값·배신 및 개인 서약/승계가 통합 | 사용자 결정 명세 있음. 게임 구현은 남음 |
| 6. 통합·배포 | 초기 세계/기존 저장·언어·설정·호환성·성능·설치/의존성 정리 후 검증 범위에 맞게 공개 | EN/KO, 1.6/1.7 분리 빌드·공용 데이터·로컬 묶음·Contracts 커버 추가, GitHub 소스 게시 진행. Contracts Workshop 공개와 실제 엔진 종합 검증은 보류 |

개발은 전체 흐름 우선 방식을 유지한다. 1~4단계의 최소 흐름을 연결하며, 구조가 안정된 뒤 상세 기능과 5단계 확장을 붙인다. 기존 다섯 Honor 모드의 검증·배포 이력을 신규 Contracts의 완료 증거로 사용하지 않는다. 최종 배포 계획은 기존 5개 + Honor.Contracts의 **6개 모드**이며 Preview는 별도 정식 모드로 더하지 않는다.

현재 상세 구현 범위와 제한은 [CONTRACTS-PREVIEW](CONTRACTS-PREVIEW.md), 확정 규칙은 [CONTRACTS-DECISIONS](CONTRACTS-DECISIONS.md)를 참조한다.

## 남은 작업량 추정과 보고 기준 — 2026-10-25 / 0.3.19

사용자 요청에 따라 이후 개발 완료/진척 보고에 여섯 단계의 남은 비율·큰 작업 묶음·현재 집중 단계를 함께 표시한다. 아래는 **실제 연결 코드를 완성하기 위한 잔여 노력의 추정치**이며 기능 개수나 테스트 수로 계산한 객관적 진척률이 아니다. 단순 모델/진단 추가나 버전 상승만으로 비율을 줄이지 않는다. 큰 기능을 연결하거나 API 조사로 작업 규모가 달라질 때 재평가하며, 추정 변경 이유도 설명한다. 단계별 분모와 작업 난도가 다르므로 단순 평균으로 전체 완료율을 만들지 않는다.

| 단계 | 남은 비율 추정 | 남은 큰 작업 묶음 추정 | 핵심 남은 구현 |
|---|---:|---:|---|
| 1. 계약·정치 구조 | 약 55% (45~65%) | 7~9개 | 미지원 주민/노예·지도자 합류/승계, 로딩 맵·복잡 재고 보존, 전체 합병, 전시 가입/이적, 정당한 독립, 상위/점령/진행 중 영지 소실과 후손 처리, 전체 흐름·복구 통합 |
| 2. 영지·공납·의무 | 약 85% (75~95%) | 5~7개 | 징수관/상단, NPC 공납, 영지 경제, 군사/보호 의무, 미이행·감면·정산 통합 |
| 3. 전쟁·항복·구원 | 약 95% (90~100%) | 6~8개 | 월드 턴 전쟁, 포위/항복/점령, 실제 전투 개입·병력 손실, 구원 퀘스트와 계약/외교 반영 |
| 4. 명예·정치·분쟁 | 약 90% (80~100%) | 5~7개 | 세력 명예 사건 연결, 신뢰/이탈 압박, 영향력·표결, 강권/제재, 중재·분쟁 결투 통합 |
| 5. 용병단·개인 봉신 | 약 100% (95~100%) | 6~8개 | 용병단 고용/정산·파견/귀환, 손실/포로/몸값, 해지/배신/제공 세력 책임, 개인 서약/승계 |
| 6. 통합·배포 | 약 70% (55~85%) | 4~6개 | 전체 신규 기능의 기존 저장/버전/타 모드 호환, 성능·오류/언어·설정 마무리, 종합 검증과 공개 배포 준비 |

큰 작업 묶음은 관련 기능의 **구현·영한 안내·저장/중단 복구·두 타깃 코드 검사**를 함께 다루는 계획 단위다. 한 번의 대화/커밋/버전이나 고정된 시간 단위가 아니며, 독립적으로 진행 가능한 묶음도 있다. 현재 집중 단계는 **1단계**다. 지도자의 저장 참조 전출이나 포로 보존의 세부 범위 확장은 일부 묶음의 부분 진척이며, 개인 합류/승계·물리적 여행·전체 합병까지 끝났다고 계산하지 않는다.

**직접 플레이/엔진 실행 검증은 별도로 보류 중이며 위 비율로 완료를 주장하지 않는다.** 1.6의 참조/Framework 검사와 실제 1.6 게임 실행은 구분한다. 6단계는 마지막에만 시작하는 작업이 아니라 다른 단계가 완성될 때 함께 진행하므로 앞 단계 변경으로 잔여량이 늘 수 있다. 소요 시간을 확인하지 않은 작업에 확정 시간/완료일을 붙이지 않는다.
